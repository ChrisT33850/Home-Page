# Home-Page
TO configure new Home Page for Helpdesk agent
📱 Frontend (LWC)
├─ helpdeskKanban → Affiche un Kanban drag-drop
└─ agentsOnline → Affiche les agents avec leurs statuts

↕️ (Communication via Apex)

🔧 Backend (Apex)
├─ HelpdeskKanbanController → Gère les données du Kanban (cases, colonnes)
└─ AgentsOnlineController → Gère les données des agents (statuts Omnichannel)
